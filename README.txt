SHAIK KHWAJA — REFERENCE-STYLE RESUME WEBSITE
================================================

This website recreates the overall layout of the screenshot you shared:
- Dark black/navy background with gold accents
- Compact top navigation
- Hero section with name, role and portrait
- About card
- Icon-style skills grid
- Experience timeline/cards
- Featured certification and certification tiles
- Colour-gradient project cards
- Professional highlights
- Contact details and footer
- Responsive layout for mobile and desktop

FILES
-----
index.html   Website content
style.css    Design and responsive layout
script.js    Mobile navigation and personal contact settings

RUN LOCALLY
-----------
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome.
4. For editing, open the folder in Visual Studio Code.
   You can install the Live Server extension and click "Go Live".

PERSONALIZE BEFORE PUBLISHING
-----------------------------
1. Add your own portrait photo to this folder and name it profile.jpg.
   The hero image area will automatically show it.
2. Open script.js and update:
   - email
   - linkedin
   - phone
   - displayPhone
3. Review all skills, project descriptions and certification tiles.
   Keep only the certifications/training you can verify.
4. The DXC experience dates are shown as May 2020 – May 2024.
5. Add a PDF resume if you want a download button; this reference-style
   version currently focuses on the sections visible in your screenshot.
   A PDF download button can be added once your final resume PDF is ready.

FREE HOSTING WITH NETLIFY
-------------------------
1. Go to https://www.netlify.com/ and create an account.
2. Choose Add new site > Deploy manually.
3. Drag the extracted folder (the one containing index.html) into the upload area.
4. Netlify will publish the website and provide a public URL.
5. You can change the generated site name in Site configuration.

NOTES
-----
This is a static HTML/CSS/JavaScript website. It has no server-side database
or working form backend. The email and LinkedIn links open the visitor's
email app/profile. The Google Fonts import requires internet access.
